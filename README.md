# NetWatch – Network Monitoring System

## Project Overview
NetWatch is a network monitoring system designed to help monitor and manage network-related information through a user-friendly web interface.

## Technologies Used
- React.js
- Node.js
- JavaScripts
- MySQL
- HTML
- CSS

## Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd NetWatch
```

### 2. Backend Setup

```bash
cd backend
npm install
```

Create a `.env` file using `.env.example` and configure your local database credentials.

Start the backend:

```bash
npm start
```

### 3. Frontend Setup

Open another terminal:

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed in your terminal.
